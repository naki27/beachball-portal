# 決定の記録（ADR）

**1 ファイル 1 決定**。設計書（`docs/design/`）にない判断をしたときに書く（`CLAUDE.md` の「規約」）。

## ファイル名

`NNNN-<slug>.md`（例: `0001-rls-for-new-tables.md`）。番号は `0001` から順に振る。

## 書く項目（この 4 つの見出しで）

1. **背景** — 何を決める必要があったか。関係する設計書の節
2. **決定** — 何をどうすることにしたか
3. **理由** — なぜそうしたか
4. **却下した代替案** — ほかに何を考え、なぜやめたか

## 決まり

- 決定を変えるときは、古いファイルを消さずに新しいファイルを書き、古いほうの先頭に「`NNNN` で置き換え」と記す
- 設計書そのものを直す判断は、`docs/design.md` を差し替えて `bash tools/split-design.sh` を再実行する。それまでの間もここに残す
