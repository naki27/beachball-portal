# 0030 審判の資格（審判級・審判No）は人物の任意の項目にする

## 背景

2026-09-21 の追加仕様（`docs/p0-tasks.md` §8 K-01）で、選手に審判の資格を持たせることになった。

- 審判級: A（赤）・B（黄）・C（白）・なし
- 審判No: 数字 6 桁
- どちらも**任意**の登録情報
- 審判級は色でも分かれているので、画面でも色で分かるようにしたい

設計書（§5.5・§5.11・付録 A）には審判の資格の項目がなく、
どこに持たせるか・誰に見せるか・色をどう扱うかが決まっていなかった。

## 決定

**1. 持たせる場所は `members`（人物）。`team_members`（所属）ではない。**

`members.referee_grade`（`'a' | 'b' | 'c'`・なしは `null`）と `members.referee_no`（`text`）を足した（マイグレーション 0018）。
`referee_no` は先頭の 0 を落とさないため `text` にし、`^[0-9]{6}$` の CHECK を付けた。

**2. 名寄せ（§8.3）のキーには入れない。**

`src/lib/matching.ts` の `MatchKeys` / `PersonInput` は氏名・ふりがな・生年月日・性別のまま変えない。
審判の資格は「同じ人かどうか」の判断材料ではない。

**3. 見せる範囲**

| 項目 | 見られる人 |
|---|---|
| 審判級 | 選手一覧を見られる人すべて（チームの選手・代表者・テナント管理者） |
| 審判No | **生年月日と同じ範囲**（§3.2 `viewPlayerPersonal`: 代表者以上と本人） |

級は「このチームに A 級が何人いるか」をチームの中で共有したい情報なので、選手にも見せる。
審判No は個人に振られた番号なので、生年月日と同じ扱いにする。権限表（§3.2）に行は足さず、既にある `viewPlayerPersonal` を使う。

**4. 入力する画面と、空欄の意味**

入力は `PlayerForm`（選手の追加・選手の修正・個人で登録・自分を選手として登録）と、メンバー管理（テナント管理者）の登録情報の修正。
**申込の選手枠（§5.5）には入れない**（申込は出場者を決める操作で、資格の登録ではない）。

空欄の意味は画面によって変える:

- **修正の画面**（今の値を出している）→ 空欄は「なし」。消せる
- **追加の画面**（今の値を出していない）→ 空欄は「変えない」。名寄せで既にある人物に結びついたとき、
  その人の資格を空欄で消さない（`refereeGrade` も `refereeNo` も空なら書き込まない）

**5. 色は CSS 変数だけで持ち、色だけに頼らない**

`tokens.css` に `--referee-{a,b,c}`（文字）・`-surface`（面）・`-border`（枠）・`-mark`（丸い印）を置き、協会ごとに差し替えられるようにした（§5.17）。
赤・黄・白をそのまま文字色にすると読めないので、**文字は濃い色、丸い印だけが級の色**にしてある（黄の枠は `#ca8a04` が白の上で 2.94:1 と足りないので `#a16207` に落とした）。
印は `aria-hidden` で、ラベルには必ず「審判 A級（赤）」のように級と色名を文字で入れる（§4.5 原則 2）。

## 理由

- 審判の資格は人に付くもので、チームを移っても変わらない。所属（`team_members`）に持たせると、
  同じ人が 2 チームで違う級になりうる
- 追加の画面で空欄を「なし」と読むと、**A 級の人をほかのチームの代表者が追加しただけで資格が消える**。
  追加の画面は今の値を出していない（ほかのチームの人の資格を見せてしまうため出せない）ので、空欄は「変えない」と読むしかない
- 申込の選手枠に足すと、枠ごとに資格を持つことになり、名簿の値とどちらが正しいかが決まらない

## 却下した代替案

- **`referee_no` を `integer` にする** — `012345` の先頭の 0 が落ちる。番号は数量ではないので文字列にした
- **審判級を「なし」という値（`'none'`）で持つ** — 「未登録」と「なしと答えた」を区別する必要がない。`null` 1 つで足りる
- **審判Noも選手全員に見せる** — 個人に振られた番号で、名簿として持ち出されうる（§12「最小公開」）。生年月日と同じ範囲にした
- **級が「なし」なら審判Noを入れさせない** — 級を思い出せないが番号は控えている、という入れ方を塞ぐ理由がない。どちらも独立した任意の項目にした
- **申込の選手枠にも審判の資格を出す** — 申込の確認ページが長くなり、枠ごとの値と名簿の値がずれる。名簿（選手一覧）だけで持つ
