# 0025 前回コピーは、取り消した申込からも戻す

## 背景

B-11 で前回コピー（設計書 §5.5(b)）を作った。§5.5(b) は「そのチームの**直近の申込（取消・削除でないもの）**から選手枠の選択状態を復元する」と書いている。
一方 §5.5(d) は取消について「取り消したあとで出ることになったら、締切前なら新しい申込として申し込み直す（**前回コピーで選手を戻せる**）」と書いている。

1 つの大会にしか申し込んでいないチームが、その申込を取り消してから申し込み直す場合、(b) のとおりに取消を除くと戻せる申込がなく、(d) の「前回コピーで選手を戻せる」が成り立たない。

## 決定

**取り消していない申込を優先し、それがなければ取り消した申込から戻す**（削除済みの申込・削除済みの大会の申込は対象外）。
画面には「前回（◯◯大会・取り消した申し込み）と同じ選手にしました」と、どこから戻したかを出す。

## 理由

- (d) の「申し込み直せる」を成り立たせつつ、(b) の「取消は候補として弱い」という意図（取り消していない申込を先に見る）も守れる
- 取り消した申込も、そのチームの代表者が自分で作った申込。中身（選手の氏名）を代表者に戻して見せることは §3.2 の権限の範囲を広げない
- 復元するのは**いまの選手一覧にいる人だけ**（脱退・削除された人は外す）なので、古い申込から戻しても名簿と食い違わない

## 影響

- `findLatestEntryForTeam`（`src/lib/repo/entries.ts`）は状態で絞らず、`submitted` を先に並べる
- 応答に `cancelled` を足した（`GET /api/[スラッグ]/teams/:id/entries/latest`）
